# AutoGluon fork required for TabBench-LLM reproducibility
#
# High-dimensional omics matrices have thousands to tens of thousands of features
# (TCGA RNA-seq has ~60k genes). The official AutoGluon release caps tabular
# foundation models (TabPFN v2, TabICL, TabDPT, MITRA, …) at 500 features and
# silently skips them on larger datasets. This fork removes that cap so all
# foundation models run on the full feature resolution used in the benchmark.
#
# Install this BEFORE installing tabbench-llm:
#
#   pip install -r requirements-autogluon-fork.txt
#   Install the remaining model dependencies directly from their upstream sources.
#
# Fork: https://github.com/mario-koddenbrock/autogluon
